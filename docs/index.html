How to interpret these results

Results use a hypothetical flat 1-unit stake at the saved odds. Win rate and ROI exclude pushes from their denominators.

Both sides of a line are tracked independently, so the combined profit and ROI do not represent a realizable betting strategy.

Positive EV means the model estimated an advantage at prediction time; it is not evidence of a profitable edge until validated on settled results.

Understanding the results

Predictions: Number of historical player-game predictions evaluated in each market.

MAE: Mean Absolute Error. The average difference between projected and actual points, rebounds, or assists.

RMSE: Root Mean Squared Error. Gives greater weight to large prediction misses.

Bias: Average projected value minus actual value. Negative means the model tends to underestimate.

Method: Historical predictions use prior game data. A minimum of 10 previous games is required.

Important: The historical backtest may evaluate a different model version than current live predictions. Backtest projection accuracy does not establish profitable betting performance.

Data: ESPN NBA game logs and DraftKings odds via The Odds API.

Model: Version 3 (experimental).

Current predictions are displayed separately from historical graded predictions.

Game times are Eastern Time. Refresh Data reloads published results, not live sportsbook odds.

Model EV is a theoretical estimate, not a verified betting advantage. For informational purposes only.
