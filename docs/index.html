Understanding the results

Predictions: Number of historical player-game predictions evaluated in each market.

MAE: Mean Absolute Error. The average difference between projected and actual points, rebounds, or assists.

RMSE: Root Mean Squared Error. Gives greater weight to large prediction misses.

Bias: Average projected value minus actual value. Negative means the model tends to underestimate results.

Method: Each historical prediction uses only games played before the game being tested. A minimum of 10 previous games is required.

Not yet measured: Historical betting win rate, probability calibration, and verified sportsbook ROI. These require recorded betting lines and odds.

Data: ESPN NBA game logs and DraftKings odds via The Odds API.

Model: baseline-normal-v1-unvalidated. Projections use weighted historical averages and a normal distribution approximation.

Game times are Eastern Time. Refresh Data reloads published predictions and backtests, not live sportsbook odds.

Backtest results measure historical projection error and do not establish profitable betting performance. For informational purposes only.
